# moonohos_ohos

HarmonyOS platform packages for [MoonOHOS](https://github.com/shop1111/MoonOHOS) native modules.

| Package | Purpose | NDK library |
|---|---|---|
| `shop1111/moonohos_ohos/hilog` | `Logger::new(domain, tag)` with `debug/info/warn/error/fatal`; messages are passed as a `%{public}s` argument, never as the format string | `libhilog_ndk.z.so` |
| `shop1111/moonohos_ohos/rawfile` | `read`, `read_text`, `list` for packaged `resources/rawfile` files through a borrowed `Manager` (adapted from ArkTS `resourceManager`) | `librawfile.z.so` |
| `shop1111/moonohos_ohos/task` | `cancelled()` / `check()` observe the `CancelToken` of the running MoonOHOS async task | — |
| `shop1111/moonohos_ohos/deviceinfo` | `get(field)`, `snapshot()`, `sdk_api_version()`: device type, brand, model, OS name and version (`deviceinfo.h`) | `libdeviceinfo_ndk.z.so` |
| `shop1111/moonohos_ohos/netconn` | `has_default_network()`, `is_metered()`; needs `ohos.permission.GET_NETWORK_INFO` | `libnet_connection.so` |
| `shop1111/moonohos_ohos/vibrator` | `vibrate(ms, usage=Touch)`, `cancel()`; needs `ohos.permission.VIBRATE` | `libohvibrator.z.so` |
| `shop1111/moonohos_ohos/surface` | `Surface::open(surface_id)` for an ArkUI XComponent, `present`/`present_canvas` of RGBA 8888 pixels, `VSync::request_frame(callback)` on the VSync thread (through the MoonOHOS gate), and a host-testable `Canvas` (0.9, docs/XCOMPONENT.md) | `libnative_window.so`, `libnative_vsync.so` |

## Generated system bindings (`sys/*`, 0.8)

`shop1111/moonohos_ohos/sys/<module>` packages are generated by `moonohos bindgen` from the HarmonyOS SDK API 26 headers: `accesstoken`, `battery`, `bluetooth`, `deviceinfo`, `display`, `hidebug`, `hitrace`, `osaccount`, `qos`, `sensor`, `syscap`, `timeservice`, `vibrator`, `wifi` (160 functions). SDK objects are handles (`pub type`, released by their Destroy function or when garbage collected; use after destroy raises `SysError::Closed`), and callbacks take MoonBit closures. Each directory's `BINDINGS.md` lists the bound functions with their MoonBit signatures and the skipped ones with the reason. Functions returning an error-code enum raise `SysError`; enums keep unknown values as `Other(Int)`. On the host they return zero values (error-code functions report 801).

```moonbit
let (x, y) = @display.get_display_position(@display.get_default_display_id())
let zone = @timeservice.get_time_zone()
let listener = @display.register_display_change_listener(id => println(id))
```

Each package carries a `moonohos.native.json` descriptor, so the MoonOHOS CLI cross-compiles its C stub for `arm64-v8a` and `x86_64` and records it in the package manifest. Without the bridge (`moon test` on Windows/Linux/macOS) the stubs use host fallbacks: HiLog prints to stderr, `rawfile.host_manager(dir)` reads a directory, `task.host_set_cancelled` simulates cancellation, `deviceinfo` reports placeholders (`is_device()` is false), `netconn.set_host_state` sets what is reported, and `vibrator.host_observations` records calls, and `surface` fails to open with 801 while `Canvas` works.

Errors carry the NDK error code; code 201 (permission denied) names the missing permission.

```moonbit
/// Counts packaged documents on a worker thread, logging progress.
pub fn count_documents(resources : @rawfile.Manager, dir : String) -> Int raise {
  let log = @hilog.Logger::new(0x4d4f, "MySearch")
  let mut characters = 0
  for name in @rawfile.list(resources, dir) {
    @task.check()
    characters += @rawfile.read_text(resources, dir + "/" + name).length()
  }
  log.info("indexed " + dir + ": " + characters.to_string() + " characters")
  characters
}
```
